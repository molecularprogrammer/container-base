## [fetch_deps.yaml](fetch_deps.yaml)

Configuration for a light-weight package manager that pulls in files/folders from git repos and
git-ignores them. `fetch_deps.lock` and `.gitignore` are modified by this.

Tasks that need fetched files should be setup to depend on it. Optionally run directly with
`task.sh fetch`.
